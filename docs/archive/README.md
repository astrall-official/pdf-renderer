# Archivo

Documentos cerrados u obsoletos de pdf-renderer. No se actualizan y no son fuente vigente: lo vigente
está en `CLAUDE.md`, `DEVELOPMENT.md`, `docs/backlog.md`, `docs/facts/` y los tests.

- **Backlog resuelto:** un archivo por cierre, `backlog/AAAA-MM-DD-HHMM-<tema>.md` (hora con
  `date +%Y-%m-%d-%H%M`). Lleva el ítem tal como estaba y la evidencia de cómo se cerró.
- **Ramas viejas:** no se archivan aquí, sino como tag `archive/<rama>` en GitHub.
